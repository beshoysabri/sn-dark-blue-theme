Dark Blue

The native Standard Notes Dark palette, with the purple accent swapped for blue — and the whole app set in Inter.

v2.4.0

Install

https://beshoysabri.github.io/sn-dark-blue-theme/ext.json
  1. Open Standard Notes → Preferences → General → Advanced Settings
  2. Paste the link under Install Custom Plugin
  3. Pick Dark Blue from the Appearance menu

What actually changed

Every background, border and shadow is identical to the built-in Dark theme. The accent moves from purple to blue, and the app is set in Inter — italics included, since the variable font ships in both styles.

Since v2.3.0 this covers the sidebar, note list and menus too, not just Super notes. v2.2.0 scoped it to the editor alone.

Code keeps its monospace face. That rule is listed after the app-wide one, so it wins at equal specificity:

pre, code, kbd, samp, pre *, code *,
[class*='code-' i], [data-lexical-code]

If this paragraph renders in Inter, the woff2 files resolved over Pages. This page loads them by relative path because a browser fetches it directly; the theme names the same files by absolute URL, because Standard Notes inlines theme CSS and a relative path would resolve against the app's own origin.

Notes

Desktop and mobile need Inter installed on the device. The desktop app sets default-src 'self' blob: with no font-src, so it refuses to download any webfont — a data: URI included. A font already installed needs no download, so it just works: get Inter, install it, restart the app. Confirmed on macOS, iOS and Android. Without it you still get the colours, with the system font.

The Daily notebook uses the app's danger token for today's date and the create-note button, which reads red on a blue theme. Since v2.4.0 those specific elements are repainted with the accent — destructive controls stay red.

Inter carries no Arabic or CJK glyphs — those scripts fall through to the next family in the stack rather than rendering as boxes.
